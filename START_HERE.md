## 🎯 How to Invoke an Agent

### Simple Formula
```
runSubagent(
  description: "Brief task (3-5 words)",
  prompt: "Detailed requirements and context"
)
```

### Example 1: Create Feature
```
runSubagent(
  description: "Create loan refinancing feature",
  prompt: "Implement loan refinancing where users can:
           - Select existing loan to refinance
           - Choose new interest rate
           - Recalculate total interest
           - Send SMS notification
           Reference UserDetails.tsx for patterns"
)
```

### Example 2: Fix Bug
```
runSubagent(
  description: "Fix Dashboard not updating",
  prompt: "Fix bug where Dashboard user list doesn't refresh after payment
           Error: setState not triggering re-render
           See console for error stack trace"
)
```

### Example 3: Optimize Performance
```
runSubagent(
  description: "Optimize Dashboard load time",
  prompt: "Profile and optimize Dashboard page:
           - Identify slow renders
           - Reduce unnecessary re-renders
           - Optimize API calls
           - Implement memoization"
)
```
